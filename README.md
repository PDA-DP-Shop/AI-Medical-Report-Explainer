# 🧠 AI Medical Report Explainer

AI Medical Report Explainer is an intelligent web application that analyzes medical report images and provides simplified explanations in multiple languages to help users better understand their health reports.

The system leverages Vision AI capabilities to interpret medical values such as HbA1c, Blood Sugar, and Cholesterol and convert complex medical terminology into easy-to-understand explanations.

---

## 🚀 Features

- Upload medical report images (PNG, JPG, JPEG)
- Automatic extraction of medical values
- Simple explanation of test results
- Multi-language support:
  - English
  - Hindi
  - Gujarati
  - Chinese
- AI-powered interpretation using Vision AI
- User-friendly interface

---

## 🧠 Problem This Project Solves

Many patients receive medical reports but struggle to understand complex medical terminology and lab values.

This project helps bridge the gap between medical data and patient understanding by translating technical medical information into simple explanations.

---

## ⚙️ How It Works

1. User uploads a medical report image.
2. The system processes the image using Vision AI.
3. Medical parameters are extracted from the report.
4. The AI analyzes the values.
5. A simplified explanation is generated.
6. The result is displayed in the selected language.
